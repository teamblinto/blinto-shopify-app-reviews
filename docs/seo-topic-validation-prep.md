## 6. Search Intent & Keyword Framework for Shemanto Review

For each pilot review, verify these query groups rather than looking only at one keyword:

1. **Primary transactional/investigation:** `[app name] review`
2. **Pricing:** `[app name] pricing`
3. **Alternatives:** `[app name] alternatives`
4. **Comparison:** `[app name] vs [closest competitor]`
5. **Category:** `best Shopify [category] apps`
6. **Problem/use case:** Shopify + merchant problem terms (e.g. post-purchase upsell, product reviews, subscriptions, landing page builder, loyalty program)

Recommended first comparison pairs:

- AfterSell vs ReConvert
- Judge.me vs Loox
- Appstle vs Recharge
- PageFly vs GemPages
- Smile.io vs BON Loyalty
